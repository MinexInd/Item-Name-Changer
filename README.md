# Item Name Changer (v1.3)

A lightweight Fabric mod that lets you rename and customize your items using powerful commands or a simple GUI editor—without anvils or experience levels.

### Lore Editing Support

- Add, remove, and edit multiple lore lines

### Improved Customization

- Separate color controls for item names and lore
- Easier formatting without needing to memorize color codes

---

## Important Note

If you are using a resource pack with custom item models or name-based CIT, use the following command:

```text
/customname <name>
```

For everything else—including editing names, adding lore, and applying colors or formatting—you can use the GUI.

Open it with the configurable keybind found in the Controls menu. The default key is `G`.

---

## Features

- Rename items with custom names and formatting codes
- Add and edit multiple lines of lore
- Use a color picker for easier styling
- Customize items through a modern GUI editor
- Save changes permanently across relogs and server syncs
- Keep separate configurations for different worlds and servers
- Automatically restore saved names and lore
- Client-side only, so it works on any server
- Lightweight and optimized

---

## Commands

### `/customname <name>`

Renames the item you are currently holding.

Examples:

```text
/customname My Cool Sword
/customname Golden Blade
```

### `/customname restore`

Restores the held item's name from the saved configuration.

### `/customname restoreall`

Restores the names of all saved items.

## Installation

1. Install Fabric Loader.
2. Install Fabric API.
3. Download the mod JAR file.
4. Place it in your `.minecraft/mods` folder.
